# Portfolio de Deep Learning & Inteligencia Artificial 🧠

Bienvenido a mi portfolio. Aquí agrupo mis proyectos académicos más destacados desarrollados durante la asignatura de Programación para la IA. Se enfocan en arquitecturas complejas, visión artificial y modelos generativos usando PyTorch.

## 📌 Proyectos Incluidos

1. **[Representación Neuronal Implícita (INR) para Imágenes](./01_INR_Image_Superresolution)**: Reconstrucción y superresolución de imágenes superando el overfitting mediante el ajuste de frecuencias en el Positional Encoding.
2. **[Variational Autoencoder (VAE) con Fashion-MNIST](./02_VAE_FashionMNIST)**: Entrenamiento de un modelo generativo aplicando la Divergencia KL para la regularización del espacio latente.
3. **[Clasificación Jerárquica en CIFAR100](./03_CIFAR100_Hierarchical_Classification)**: Optimización del rendimiento de clasificación evaluando etiquetas finas vs. gruesas.

*Tecnologías usadas: Python, PyTorch, Matplotlib, NumPy.*
